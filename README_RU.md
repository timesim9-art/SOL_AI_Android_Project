# SOL AI — Android starter project

## Что уже работает
- Нативный Android-интерфейс на Jetpack Compose.
- Чат с историей сообщений в рамках текущего запуска.
- Подключение к OpenAI-compatible Chat Completions API через введённый API-ключ.
- Поле для выбора модели и отдельное поле ключа fal.ai.

## Важно про «всё вместе»
Для реальной генерации изображений и видео нужны отдельные запросы к выбранным моделям/endpoint-ам fal.ai. Этот проект пока содержит UI и поле ключа, но не выдаёт генерацию за готовую функцию. Выбор модели и её API меняются, поэтому endpoint надо закрепить под конкретные модели.

## Сборка APK
1. Установи Android Studio на компьютер.
2. Открой папку проекта `SOL_AI_Android`.
3. Дождись Gradle Sync.
4. Подключи Android-телефон с USB debugging или выбери эмулятор.
5. Нажми Run. Для APK: Build → Build Bundle(s) / APK(s) → Build APK(s).

## Запуск только с телефона
Можно открыть проект в Android-IDE на Android, поддерживающей Gradle, но самый надёжный способ сборки — Android Studio на ПК.

## Настройка чата
В приложении открой шестерёнку, введи свой API key и модель (по умолчанию `gpt-4o-mini`). Не вставляй ключ в публичный репозиторий.

## Безопасность
В этом демонстрационном личном клиенте ключ живёт только в памяти процесса и не сохраняется на диск. Прямое использование секретного ключа в мобильном приложении не подходит для публичного релиза: для него нужен собственный backend, который хранит ключи и ограничивает расходы.
